# tasks-engine

Общий движок сайтов с подборками задач по темам: с разборами, ответами и видео.
Сейчас на нём работают [kege2.ru](https://kege2.ru) (ЕГЭ по информатике)
и [mathege2.ru](https://mathege2.ru) (ЕГЭ по профильной математике).
Сам движок к экзамену и предмету не привязан.

Здесь лежит всё, что одинаково на всех сайтах: шаблоны страниц, шапка, стили
и скрипты страниц заданий. Контент (задания, статьи, новости, картинки) хранится
в репозитории каждого сайта.

## Подключение к сайту

В `_config.yml` сайта:

```yaml
title: КЕГЭ 2                          # название в шапке и в og:site_name
subtitle: Полный курс подготовки к ЕГЭ  # строка под названием (необязательно)
description: …
url: https://kege2.ru
lang: ru

remote_theme: danilov0artem/tasks-engine  # можно зафиксировать версию: …/tasks-engine@v1

news_channel:                          # ссылка в шапке (необязательно)
  url: https://t.me/…
  text: Новости в Telegram

contacts:                              # блок «пишите автору» на главной (необязательно)
  vk: https://vk.com/…
  telegram: https://t.me/…

tasks_engine:                          # настройки страниц заданий
  api_base: https://api.kege2.ru       # без него — только локальные задачи
  default_source: kompege              # источник задачи по умолчанию; без него — "local"
  source_label: kompege.ru             # подпись «(задача N с …)» у задач из API
  files_base: https://kompege.ru       # база для относительных ссылок на файлы из API

plugins:
  - jekyll-remote-theme
  - jekyll-sitemap
```

## Шаблоны

- `layout: home` — главная: слева новости (`/data/news.json`) и контакты, справа
  содержимое страницы (обычно список заданий).
- `layout: default` — статьи и страницы заданий. Для страницы заданий добавьте
  `task_page: true` и в теле задайте `window.TASK_PAGE_CONFIG` (темы → задачи).
  Задача с `source: "local"` берётся из `localTasksUrl` (JSON рядом со страницей),
  остальные — из `tasks_engine.api_base`.

Файлы движка публикуются в `/assets/css/` и `/assets/js/`.

Любой файл темы можно переопределить на конкретном сайте, положив файл с тем же
путём в его репозиторий.

## Разработка

Сайты запускаются локально через `./serve.sh`: он берёт тему из соседней папки
`../tasks-engine`, поэтому правки здесь видны на сайте сразу, без пуша.

После пуша в `main` workflow `rebuild-sites.yml` пересобирает оба сайта
(нужен секрет `PAGES_TOKEN`, см. комментарий в файле).
